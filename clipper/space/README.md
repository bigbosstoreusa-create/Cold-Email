# 🎬 Home Clipper

Transforme une longue vidéo en shorts viraux (≤ 1 min) : meilleurs moments,
score de viralité, recadrage qui suit le visage, sous-titres karaoké & emojis.

Dépose une vidéo (ou colle un lien), choisis tes options, récupère tes clips.
Tout tourne dans ce Space. Voir `DEPLOY.md` pour les détails de déploiement.
